# edunext-assets

Default event posters, one per EduNext event type. The events worker (`edunext-event-worker`) links to them
through jsDelivr (`https://cdn.jsdelivr.net/gh/moldod12/edunext-assets@main/<file>`) when a source gives no image.
Keep the PNGs in `edunext-event-worker/default_images/` identical to these.
